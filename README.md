# dotk-covenants

The covenant contracts of [dotk.name](https://dotk.name), the `.k` name registry on Kaspa. Each
directory holds contracts and a verifier that proves that mainnet runs on them.

| Directory | Content |
|---|---|
| [`registry/`](registry) | The gap and deed contracts of the name registry. |
| [`market/`](market) | The sale escrow of the dotk market, and the guide for a venue that opens listings. |
